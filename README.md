# Garee Shahada
### check out website version at https://gareeshahaadaa.flutterflow.app/
### app on playstore https://play.google.com/store/apps/details?id=gareeshahada.com&pcampaignid=web_share
Garee Shahada is a mobile app built using **FlutterFlow** and **Flutter**, designed to deliver audio content and a smooth user experience with deep linking support.  

---

## Features

- **Audio Playback**: Play audio tracks from a predefined list.
- **Deep Linking**: Support for custom URL scheme (`gareeshahada://`) for direct navigation to content.
- **Media Ads**: Integrated with Google AdMob for in-app monetization.
- **Custom State Management**: Uses FlutterFlow's `FFAppState` to manage audio and app state efficiently.
- **Cross-Platform**: Runs on both Android and iOS devices.
